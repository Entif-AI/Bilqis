# U7D Kev's Semantic Laboratory: interactive, source-grounded U4/U6 worlds

Stacked on Bilqis draft #113 at verified head d2850f9eecb6138b7442e8927286894ff7b5d2da. The worker owns only branch codex/u7d-kev-semantic-laboratory, one isolated worktree. Public research data only. Historical U6/U7/U7B/U7C checkpoints and shared FEATURE_LOG remain unchanged.

U7D is a finite, interactive research test, not a substitute for deterministic semantic gold. Each of 24 training-free DEV investigations has eight dossiers and ten action opportunities. Eight explore U4 two-interpretation nested AND/OR/NOT evidence (including ambiguity), eight test U6 three-event content-origin versus reasoning-premise ancestry, and eight test U6 current/historical supersession effects. Each intervention rewires one report proposition assignment or edge kind, preserving entity/report/link counts. Two independent source-grounded oracles must agree before admitting every original and counterfactual record.

At each step the teacher sees a cumulative **English-only** world description, legal English action menu and feedback. It may inspect source facts, mutate and compare a real typed-world state, submit a proposed discovery (even incorrectly), or abstain. A discovery is scored only after a verified one-factor contrast and correctly submitted finding. The hidden typed world, AST, oracle and gold never enter the model's input. Native request/response bytes, choice probability vector, model pin, transition hashes, and teacher action cost are retained for exact offline replay. The candidate order rotates without using the answer.

Frozen controls: same ten-action cap and same legal observations for random exploration and a fixed lexical heuristic. An additional **actual native Kev one-shot** baseline makes 24 one-decision dossier commitments before observation and follows a fixed Inspect/Test/Report plan, without adapting. That 24-call cost is reported separately from interactive Kev calls. These controls do not receive world oracles before actions. Initial English dossier names contain no answer hints. Each episode permits more potentially informative inspections than Kev can complete before the ten-action deadline.

Predeclared qualification gate in run-03/freeze.json: Kev must solve at least 14/24; at least 4/8 in each family; exceed random and native one-shot by at least eight; exceed the fixed heuristic by at least four; and satisfy native-error, legal-action and oracle-integrity bounds. A qualified result would permit a **new, separately predeclared** U6-step-13400 continuation capped at 64 gradients, exactly 12/4/8/8 batches with weak priorities U4=3, U6 lineage=2, U0=1, other=2, DEV stop checks every eight updates, and unopened final worlds. Failure strictly forbids any student gradient. U7D's 24 exposed DEV episodes cannot establish unbiased scientific generalization.

The first exploratory scan variant (run-01) had an exact-word heuristic solving all 24, revealed weak semantic coverage and a legal-menu answer hint. It received **zero native calls and zero gradients**. Run-02 improved scope but its frozen pair result used Python tuples that did not survive canonical JSON roundtrip. It too received **zero native calls and zero gradients**. Neither is accepted qualification evidence; both are preserved as versioned failed preparation artifacts. Run-03 is the first version admitted for actual Kev qualification after dedicated preflight tests.

Commands: python3 -m bilqis_u7d.run_v2 freeze; python3 -m unittest discover -s tests -p test_u7d_lab.py -v; python3 -m bilqis_u7d.run_v2 qualify; python3 -m bilqis_u7d.run_v2 replay. A/B/C closeout is required after actual measured results and provider readbacks.
