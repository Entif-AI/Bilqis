## Delivered behavior

Factory `verify_profile_expansion` checks a compiled successor against its exact
predecessor. Canonical curriculum, source bindings, provider implementations,
answer modalities and semantic geometry remain fixed; enabled capability scope,
declared provider dimensions and registered answer domains can widen. Narrowing,
changed identities and inconsistent compiled projections fail closed.

Native BAMF adopts the exact successor through a profile-specific v4 transition
and acceptance binding. B13 retains student parameters, matching native AdamW,
optimizer step, topology, extents, teacher, correction and baseline state. The
existing championship identity reset clears active advice. The transaction binds
the current parent, lease, signed source approval and Factory proof without A09
selection claims. Existing v1–v3 records retain their decoding and wire contracts.

Newly enabled capabilities are planning-visible. The existing frozen generated
grade remains teaching authority; adding capabilities requires that authority to
exist. Publication rechecks its activation under the B13 pointer lock. Source-only
widening does not require a new grade. Currentness proofs from the predecessor
become stale after publication. Resume reads the accepted immutable successor;
an unaccepted release file supplies no authority. Exact retry authenticates the
profile transition and current lease.

The fixed C05 founding school keeps its original questions, seed and receipt over
verified compatible profile ancestry. Its progress census includes only measured
capabilities. Package-import broad retention holds when that fixed school does not
cover the current profile; it never invents scores for newly exposed capabilities.
Non-profile ancestry needs its separately governed compatibility owner.

## Operator use

Compile the successor using the existing Factory
`compile_successor_profile_release` and persist its immutable artifact. Preview:

```sh
npm run train -- --dry-run --resume --run-dir /absolute/run \
  --factory-profile-release /absolute/successor.json
```

A human may explicitly select the same artifact with `--human-run --resume`.
The native operator validates run authority, takes its sovereign lock, adopts
before its first visit, and then uses the normal learner. Adoption itself performs
zero optimizer updates. A current v2 Atlas lease and signed source approval for
the accepted run/source release are required. Fresh/legacy profile requests reject.
The command does not compile semantics or select a developmental grade.
