## Review amendments / concrete execution
- Separate queryEpoch (page searches) and selectionEpoch (record/link hydration). Fresh search/context change/deactivation increments both; next-page search increments only queryEpoch; explicit selection/hydration increments only selectionEpoch. Selection during pagination cannot cancel page completion. Fresh search cancels stale link hydration. Next-page merge retains selection. Bound pagination duplicate clicks by ignoring append if query status is loading.
- Hook key encodes full identity to lowercase hexadecimal code points. Repeated identical identities receive occurrence suffix within that identity only; selected/page/group scopes separate namespaces. No payload deduplication or dropping. Focus restores the exact occurrence hook if still present, otherwise moves to result heading for removed pagination action; new record heading on explicit select only.
- paintEvidenceView captures existing draft kind/value, focus/caret and open disclosure hooks before replacing DOM; restores drafts unless starting a fresh submitted/reference search or changing context. Fresh-search reset applies submitted criteria intentionally; async completions preserve unsent drafts.
- Phase 1: tests/domains/evidence-workspace.test.mjs for hook uniqueness with duplicate records/refs/links; escaped literal null/false/long/XSS values; translated catalog expansion; readable/raw/provenance/state/origin. Capture baseline screenshot through a disposable local fixture harness.

Existing no-DOM host mocks remain supported.
- Phase 4: local static fixture+browser journey rendered screenshots, keyboard/320px reflow, density/themes, expansion/RTL/text spacing/reduced motion and defensive state matrix. Browser selects only explicit test hooks. Required gates and scoped drift review then review-ready PR.
