# #1295 operator error semantics

## Outcome and ownership

Issue #1295 (parent #1286, ADR-142 and ADR-146) owns classification and presentation only. Existing owners continue to decide admission, learner eligibility, comparable baselines, C05 retention, and C07 progress. No training, source/rights relaxation, curriculum engine, or changed retention thresholds.

Baseline: unified d5e3b7c3a5cec07dea7b6c0ceb30436213ee8ca6. The existing priority qualifier conflates absent release membership with an inactive school grade. B11 source-authority guards emit topology errors. C07 already returns five distinct terminal statuses. Durable learner frontier and baseline contracts are owned by #1291/#1292/#1297/#1298 and are absent at this baseline; this leaf must expose their meanings without inventing their evidence.

## Implementation contract

1. Extend the existing typed ErrorSpec catalog using a cohesive `school_authority.py` specs module, imported by SCHOOL and appended to CATALOG. Preserve the existing catalog prefix and all existing wire values. Add curriculum NOT_ADMITTED, NOT_TEACHABLE, PREREQUISITE_HELD, SOURCE_HELD, INVALID; retention BASELINE_ABSENT and COMPARABLE_REGRESSION; B11 SOURCE_EXECUTION_AUTHORITY_INVALID; C07 WAITING_FOR_EVIDENCE, HELD, IMPLEMENTATION_UNCOVERED, FIXED_POINT, and LEASE_REQUIRED. Each has an exact owner, meaningful title, message including reason, state-preserving recovery and concrete next action. Existing topology specifications and guidance remain unchanged.
2. In `_teacher/priority_qualification.py`, separate execution-plan/curriculum membership (not admitted), absent source binding (source held), and inactive school grade (admitted but not teachable). Preserve existing serialized hold strings where their meaning remains correct; add NOT_TEACHABLE. Missing offers and planning unavailability remain explicit. Replace topology errors in the five priority owner modules with curriculum INVALID. Preserve detailed reason context and exception behavior.
3. Replace topology errors at the B11 source execution authority, execution binding and feature-authority validation owners with the B11-specific catalog code. Do not alter validation predicates or row-owner logic. Errors originating from other owners retain their codes.
4. Add a pure operator projection under presentation for existing typed reasons/statuses. Map explicit prerequisite/learner holds separately from source/rights holds; baseline absence/unmeasured must never render regression. Comparable regression messages include the producer's blocking capability or scope when present; missing blocker stays explicitly unspecified. This projection grants no authority and does not infer a baseline from scores. Unknown reasons remain visible. C07 projection uses exact status rather than guessing fixed point from reason text. Wire it into actual existing School50/BAMF/Model Forensics consumers where those records are consumed; preserve raw code/reason alongside labels. Audit each consumer and record surfaces without an applicable live record instead of fabricating data.
5. Regenerate the existing operator field manual/catalog with `scripts/error_control_plane.py --write-docs`. Document ownership/next actions and the absent sibling-contract boundary.

### Phase 1: catalog and producer classification

`school_authority.py` defines these specifications. Prefixes below are literal wire namespaces. Every message is `<title>: {reason}`; every recovery preserves state. Titles and next actions below are literal English guidance; disposition is `PRESERVE_AND_INSPECT` except baseline `MEASURE_WITH_CURRENT_AUTHORITY` and fixed point `NO_READY_DELTA`.

| Namespace/member | owner | title | next action |
| --- | --- | --- | --- |
| SCHOOL.BAMF_CURRICULUM.INVALID | runtime.priority_qualification | Curriculum priority authority invalid | Reload accepted learner, release and teacher authority; inspect the detailed reason before selecting work. |
| SCHOOL.BAMF_CURRICULUM.NOT_ADMITTED | runtime.priority_qualification | Capability not admitted | Use C07 to admit a source-qualified executable capability before teaching it. |
| SCHOOL.BAMF_CURRICULUM.NOT_TEACHABLE | runtime.priority_qualification | Admitted capability not currently teachable | Rebuild the current learner frontier and inspect its eligibility evidence. |
| SCHOOL.BAMF_CURRICULUM.PREREQUISITE_HELD | runtime.priority_qualification | Prerequisite or learner evidence required | Establish the required prerequisite evidence through lawful teaching and reassess this dependent capability. |
| SCHOOL.BAMF_CURRICULUM.SOURCE_HELD | runtime.priority_qualification | Source, rights or correction authority held | Requalify the exact source binding, rights and correction epoch; preserve unrelated lawful work. |
| SCHOOL.BAMF_RETENTION.BASELINE_ABSENT | runtime.capability_retention | Baseline absent or unmeasured | Obtain a lawful baseline under the current evidence identity before comparing regression. |
| SCHOOL.BAMF_RETENTION.COMPARABLE_REGRESSION | runtime.capability_retention | Comparable retention regression | Inspect the producer's blocking capability or scope and comparable evidence; preserve the accepted learner. |

### Phase 2: pure projection and actual consumers

`presentation/authority_labels.py` exports `authority_label(reason, *, domain=None, blocking_capability=None, blocking_scope=None) -> str` and `authority_report(reason, *, domain=None) -> ErrorReport | None`. Exact recognized reason sets:

A09_PLANNING_UNAVAILABLE displays that exact reason (planning selection is not proof of a prerequisite defect).
- retention UNMEASURED, NOT_MEASURED, BASELINE_ABSENT -> BASELINE_ABSENT; PROTECTED_CAPABILITY_REGRESSION, FIXED_LESSON_GRADE_REGRESSION, ACTIVE_SCHOOL_GRADE_REGRESSION, WHOLE_SCHOOL_NET_REGRESSION -> COMPARABLE_REGRESSION only as the producer's reported decision, never inferred from numbers. Display original reason plus `blocking capability <id>` or `blocking scope <id>`; if neither exists append `blocking scope unspecified`. This is a reported decision, not proof that sibling baseline qualification exists.
- domain admission: exact five AdmissionFlywheelStatus values map to the matching SCHOOL.BAMF_ADMISSION member. Unknown values remain literal; no substring guessing. Fixed point never means mastery or complete semantic coverage.
- None/empty -> UNKNOWN; unrecognized text -> unchanged. Domain disambiguates admission HELD from source holds. Labels use spec.title; original reason stays in serialized records. No scoring or admission policy is changed.
