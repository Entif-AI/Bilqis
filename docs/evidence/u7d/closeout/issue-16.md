### U7D negative result: more world navigation did not produce causal pedagogical discoveries (11 October 2026)

The U7D successor used Kev-4B as an active investigator in a finite oracle-bound semantic laboratory, with real sequential inspect -> legal world intervention -> deterministic before/after observation -> optionally report a causal finding. The source-meaning oracle remained authoritative and typed records/ASTs were internal. Twenty-four DEV episodes spanned U4 nested evidence and U6 lineage/current-vs-history. Each had exactly one independently checked one-factor cause, eight dossiers, and a ten-action cap. The frozen qualification gate required a positive comparative win before any Bilqis gradients.

Actual Kev sequential investigation found **0/24** verified causal cases, against a fixed heuristic 8/24, native one-shot Kev 3/24 and random 1/24. Across 99 sequential decisions Kev mostly inspected (71) then abstained (24); only 4 TEST actions, no reports, all 24 first actions picked Ash, and 93/99 choice margins were LOW_MARGIN. Qualification failed; no student gradients occurred. A posthoc read-only U6 step-13400 score on the already frozen DEV pairs confirmed real student weaknesses (240/512 correct; zero of 24 gold-changing causal pairs jointly correct), but this is not Kev teacher benefit.

For #16, next acceptance should require *observed causal test-and-report behavior*, state-contingent contrast discovery and measured intervention utility, separately from native legal-action choice or semantic-recognition battery accuracy. Preserve actual option order/byte traces and low-margin/no-response choices; test action-specific incentives and honest REVIEW/abstention. Source oracle and gold remain outside Kev authority. Be careful with U7D's limitations: three TEST feedback strings showed Python list syntax in ten later model states, and engineering tests inspected final file bytes for disjointness; final was never used by Kev or training.
