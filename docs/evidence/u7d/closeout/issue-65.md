### U7D native Kev qualification for interactive worlds: no teacher-utility pass (11 October 2026)

A frozen 24-episode finite semantic laboratory compared actual Kev-4B sequential decisions against random, a transparent observation-only lexical heuristic, and a native Kev one-shot dossier commitment (24 native requests followed by open-loop testing). Each actor had the same ten-action cap and legal observe/intervene/report space. Kev's sequential action-based causal discoveries were **0/24**; heuristic **8/24**, native one-shot **3/24**, random **1/24**. Zero student updates were admitted. Native pinned model jaredpalmer/kev-4b@6cfce5c2fa4b4bd64026336ab649c5ca78857d52 MLX/BF16/MPS; 123 actual calls including 24 one-shot and 99 sequential, 39.956 seconds native request wall, reported 62,895 input and 19,395 output tokens, zero EG2.

The 99 sequential choices comprised 71 Inspect, four Test, 24 End unresolved, zero Report; all 24 first decisions chose the name Ash despite option-order rotation and 93/99 decision margins were LOW_MARGIN. Native one-shot also chose Ash in all 24 cases, exposing name bias/weak policy under this prompt. The one-shot and active native compute budgets differ and this is an exploratory author-generated DEV cohort, not general Kev incapacity. Full serialized request bytes, probabilities, order, runtime checks and exact deterministic replay are archived. One strict-language defect remains: three current/historical TEST feedback events rendered Python list notation and appeared again in ten model states; the source-run was not rewritten or reissued after this finding. The nominal sealed file was read by engineering split QA but never consumed by teacher/adaptation/training.

Future #65 evaluation should distinguish static recognition from stateful planning, calibrate option/name bias, measure meaningful legal testing and verified findings, and evaluate matched action as well as native inference/cost budgets. Do not qualify a local engine as developmental teacher from a good static score when the actual sequential utility gate fails.
