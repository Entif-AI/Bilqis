# U7D Kev Semantic Laboratory: complete native qualification, negative

**Disposition: NOT QUALIFIED; zero student gradients.** U7D was run from a fresh
isolated branch stacked on draft PR #113. The accepted U6/AdamW baseline remains
at step 13,400. Historical U7B and U7C failures and checkpoints are preserved.

The admitted run-03 used 24 independently oracle-checked interactive worlds,
with 8 episodes each in U4 nested evidence AND/OR/NOT across two live
interpretations, U6 three-event content-origin versus proof-premise lineage,
and U6 current versus historical evidence under supersession. Eight separate
final worlds were frozen and excluded from teacher and training selection.
Actions could inspect source facts, make a count-preserving one-factor world
mutation, observe deterministic English feedback, submit an independently
verified finding even when wrong, or abstain. Ten actions maximum. Gold, typed
ASTs and semantic source oracles stayed internal.

found 240/512 correct typed semantic records: U4 nested evidence 58/128,

## Integrity limits preserved, not retrospectively repaired

The first shallow run-01 freeze let a lexical heuristic solve all worlds and
contained a legal-menu answer cue; it received zero native calls or gradients.
Run-02 broadened the semantics but its archived Python tuple output did not
round-trip through canonical JSON. It also received no native calls or
gradients. Both are retained as superseded design evidence. Run-03 is the
first completed native qualification.

Three U6 current/historical TEST responses used Python list notation for a
two-state evidence result, such as ['conflict', 'conflict']. No typed AST or
gold-authoring control was sent, but this **does violate the stricter English-
only prose formatting** requirement. The original native bytes are preserved.
The eight-world final file was read by a disjointness engineering test
before native inference, though never shown to Kev, used for training or
opened to score a final endpoint. Earlier flags saying final_unopened are
therefore narrow operational flags, not literally byte-level unopened.
See run-03/validity-addendum.json for the explicit correction.

The one-shot control used 24 native Kev calls to commit dossier choices, then
a fixed three-step policy. Each actor had the same legal actions and ten-step
cap, but actual native compute and action usage were unequal and are reported.
Twenty-four related worlds remain a small authored DEV battery.

No student continuation was admitted. Any revised English feedback, stronger
incentives for intervention, genuinely sealed final custody or alternative
agent policy needs a **new frozen epoch**. This experiment is evidence about
the failure of the tested interface and agent behavior, not successful teacher
guidance or semantic acquisition.

## Additional behavioral and distribution audits

All **24 interactive first actions chose Inspect Ash**, despite rotated option order.
All **24 native one-shot selections chose Ash** too. This persistent name
preference makes the one-shot control a repeated fixed-name commitment, not a
demonstration of semantic judgment. Of 99 sequential choices, **93 were native
LOW_MARGIN** and only six OK. These results support a failure of action
selection, exploration and premature abstention; they do not establish that
Kev was incapable of reasoning about the unseen cases if it had inspected
and tested them. Three TEST transitions rendered Python list syntax in the
response, and those were subsequently visible in **ten native prompt states**
that reused observation history.

The U4 original evidence outcomes across the 64 dossiers were AMBIGUOUS 27,
UNKNOWN 2, TRUE 23, FALSE 12, and CONFLICT 0. The laboratory supports
CONFLICT through the finite oracle but the frozen U4 initial cohort did not
cover it. U6 lineage initial answers were FALSE 61/64 and TRUE 3/64.
These distributions admit label-frequency and other structural shortcuts;
no independent, executable surface-only or answer-frequency adversarial
baseline was qualified. Only the original/contrasted semantic oracle,
field-count invariance and world/disjointness gates were verified. These
limitations constrain all claims about increased difficulty and completeness.
