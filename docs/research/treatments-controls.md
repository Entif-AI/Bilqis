# Treatments and controls

SYS-B and SYS-C share the ternary student and the full developmental teacher framework. Both may use the same locked local-pedagogue policy. Their finite-world information and answerability match; their token sequence length, factor locality and induced adaptive lesson history need not. This is an integrated adaptive-system test, not an isolated causal estimate of one morpheme.

The first attribution replays an identical accepted world/query sequence in B and C. This removes response-dependent curriculum divergence while retaining representation. Next compare both representations under a difficulty-only teacher to estimate topology and its interaction with representation. A full-precision arm uses the same architecture and exposed data; precision changes forward quantization rather than parameter count. The four engineering smoke conditions exercise this factorial interface but do not estimate its effects.

A factor-isomorphic arbitrary symbol notation is a symmetry control, not a negative control expected to perform worse. Permuting token IDs and the corresponding embedding/optimizer rows preserves the model trajectory under coordinate-equivariant operations. Failure of a coupled symmetry test indicates implementation or initialization mismatch. IID unpaired initializations should be compared in distribution, not expected to be bit-identical.

The nonseparable factor-mixing control preserves the original information but changes which local coordinates align with semantic primitives. For color c and intended role p in GF(3), expose u=c+p and v=c+2p, with inverses c=2u-v and p=v-u modulo three. This is not a separate relabeling of each field. It tests semantic locality under the chosen learner. It also changes marginal/correlation statistics, which must be measured rather than denied. A joint opaque-symbol control additionally changes vocabulary economics and requires explicit parameter/coverage accounting.

A generic typed AST or schema selected without donor-language commitments is the strongest competitor to donor specificity. A Bilqis win over constrained English does not distinguish it from generic structured-data learning. A generic schema match can refute H19 while supporting H01 or H03. AMR/MRS-like and surface-Ithkuil controls require separately validated codecs, not invented translations. Those codecs are specified extensions, not implemented in the finite reference.

Intervention privileges are an experimental variable. All arms receive the same permitted information, maximum local-model calls and fallback policy. Unequal upstream help is logged as a deviation, not hidden in preprocessing. Gold labels never come from the LLM. Teacher no-help, teacher-shuffled-topology, renderer-length matching and label-balanced query-only baselines are diagnostic arms selected after the integrated result using a new analysis lock.
