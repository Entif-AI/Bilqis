# SYS-01: integrated developmental-substrate trial

Status: locally locked study design; not externally registered, not run, and not a claim of independent custody. Plan version 0.1.0. Report ETR-2026-05 v0.4.7. This plan takes the integrated demonstration first. It does not require factor isolation before the trial. Later attribution follows the observed result.

## Research object and estimand

The tested system combines a finite semantic ABI, morpheme-addressed Bilqis-inspired input, a fixed scratch-trained ternary student, a developmental teacher, rehearsal, competence probes and validated local-pedagogue proposals. The target is the total effect of the declared representational-developmental package relative to a credible constrained-language condition under a matched learning budget. It is not the effect of Ithkuil phonology, an estimate of general intelligence, or a claim that every component independently helps.

Both arms use the same student architecture, parameter count, optimizer, semantic target domain, answer head, teacher implementation, intervention privileges and maximum budget. Both use topology-guided development in the primary comparison. The integrated treatment therefore includes the common developmental substrate as an enabling system, but the comparison does not estimate the effect of that shared substrate. Representation-dependent errors may cause different lessons to be selected by the same adaptive teacher; this induced curriculum divergence is part of the total adaptive-system effect. The matched-example replay attribution later removes that divergence. A difficulty-only teacher is a later attribution, not a deliberately weakened primary baseline.

SYS-B uses `representation: bilqis`; SYS-C uses `representation: cnl`. The CNL codec exposes exactly the same finite world and query through fixed controlled-English templates. It is not a fluent general-language baseline or a TinyStories reproduction. Stronger natural-language and generic symbolic comparators belong to the attribution/extension program and are necessary for broader claims.

## Exact student and budget

Use `configs/reference-3m.json`: width 192, six layers, six attention heads, context 384, feed-forward expansion four, 512 frozen token rows, tied four-answer readout, pre-normalization and deterministic CPU reference settings. The instantiated parameter count is 2,828,736. All paired arms must have the same counted parameters. The `ternary` implementation uses ternary forward weight values and quantized forward activations with straight-through gradients over floating-point stored tensors. It does not use packed native low-bit kernels.

Primary budget: 4,096 optimizer steps, batch size 16, hence 65,536 semantic-example exposures per seed. Rehearsal/repeated examples count as exposures. Do not substitute a token budget after observing a result. Report unpadded input tokens, padded computation positions and measured compute separately. A second, explicitly labeled compute-matched analysis requires an independently locked metrology procedure and is not automatically delivered by equal example counts.

Eight paired seeds: 101, 102, 103, 104, 105, 106, 107, 108. Each pair shares initial parameter tensors and underlying generator-seed conventions. The intervention differences must not silently alter the answer head, model width, optimizer, context, label balance or teacher assistance ceiling. Pair assignment and execution order alternate B/C by seed; record actual machine load and order. A failed member invalidates its pair for the primary paired estimate until rerun under the predeclared recovery rule.

## Developmental procedure

Train in 64-step tranches. The teacher uses a prerequisite DAG, chooses among eligible stages using tranche counts, rehearses mastered prior stages, and evaluates mastery, retention and DEV transfer. Mastery uses a Wilson lower bound of 0.90; retention uses 0.85; DEV-transfer proportion uses 0.75. DEV probes contain 256 cases per evaluated stage. The formal stage graph, selection function and thresholds are executable in `bilqis_ref/teacher.py` and hashed by the engineering source lock.

These repeatedly inspected DEV quantities are curriculum decisions, not simultaneous confidence guarantees. No scientific p-value is derived from a promotion receipt. Fixed-budget final sealed evaluation is the primary outcome, even if no stage is promoted. Competence-based early graduation can be analyzed as a censored secondary endpoint, but cannot remove difficult seeds from the final denominator.

The pedagogue proposes eligible stage, bounded seed offset, focus label and rationale. The formal validator controls admissibility and the oracle controls all gold labels. The real local model is specified by exact upstream revision, local weight/tokenizer/chat-template manifest hashes, serving-engine identity and decoding parameters. The default candidate is Qwen/Qwen3-8B, whose live upstream revision was resolved; no weights were downloaded here. The candidate manifest deliberately contains null local identifiers and cannot authorize execution as-is.

At most one accepted pedagogue event is used per tranche; request/response bytes, validation/rejection reason, actual server usage and cache hits are logged. A rejection leads to the same deterministic fallback policy in both arms. No escalation to a frontier teacher, paid API or different local model is permitted midtrial. Research-plane assistance used to author this package is disclosed but is not intervention-plane training data. A no-pedagogue system is a separately labeled arm, not an unrecorded substitution.

## TRAIN, DEV and SEALED

TRAIN uses the independent-edge world family with fixed ontology and bounded AST depth. DEV uses distinct deterministic streams and may affect teaching. Reference held-out family types are cycle and block constructions. Each sealed family has 512 cases at each of five stages: 5,120 ordinary cases per final checkpoint. Stage zero is a diagnostic, leaving 4,096 primary world-sensitive cases in eight family-by-stage strata. Every stage-one-through-four primary case must have a stored legal world-only intervention that changes the correct answer while preserving its query. Score those 4,096 original/counterfactual pairs as a separate endpoint.

A custodian prepares previously unexamined concrete family implementations within the predeclared cycle/block family definitions, freezes their code and salts, checks label support and shortcut audits, and releases only authorized inputs to a frozen evaluation process. The code delivered with this package is a transparent reference, not unseen to its authors. It cannot by itself establish independent blind-family custody. The custodian must not change family definitions or rejection rules after observing arm results; a materially different family definition creates a new plan epoch.

Reject exact semantic-hash collisions against TRAIN/DEV, and audit entity-renaming isomorphism and normalized query-template overlap. Exact hash exclusion is implemented; the stronger duplicate audit remains a confirmatory-launch prerequisite. Shared ontology and primitive operators are expected; an unseen combination must be defined at the intended structural level rather than proclaimed from a new random seed. Preserve rejection counts and reasons because label balancing and witness rejection change the evaluated distribution.

The sealed gold commitment uses a fresh salt kept by the custodian, the input manifest hash and the private gold manifest. A directory permission is not an organizational trust boundary. The evaluator receives frozen model hashes and must not update weights, prompts, teacher state or thresholds. A discovered test defect causes a documented plan amendment and independent resealing before viewing condition summaries, or a clearly exploratory rerun if blinding was already lost.

## Primary analysis and decision

For seed i, compute A_Bi and A_Ci as the unweighted mean accuracy over the eight primary family-by-stage strata. Let d_i = A_Bi - A_Ci. Report all eight d_i, their mean, standard deviation, a paired t interval with seven degrees of freedom, and the exact two-sided sign-flip randomization p-value over all 256 paired sign assignments. The t interval assumes suitably independent seed-level differences; the sign-flip test assumes exchangeability/symmetry under the null, not merely many cases. The independent unit is the training seed pair, not an evaluation item or checkpoint.

A predeclared positive systems signal requires: mean d at least +0.05, the paired 95% interval lower endpoint above zero, no average primary-family degradation worse than -0.05, no unresolved integrity/custody violation, and a competent SYS-C control, defined below. Report the counterfactual-pair endpoint alongside ordinary accuracy whether favorable or not. If ordinary accuracy improves while paired consistency does not, the evidence supports a narrower performance gain and not robust world use.

The competence gate is fixed before the trial: SYS-C must average at least 0.60 primary macro accuracy and at least 0.90 stage-zero diagnostic accuracy across all eight seeds. This gate applies to interpretation, not exclusion of seeds. A competent SYS-C and a failing SYS-B count against B. If SYS-C does not pass, report the entire comparison but classify representation-efficiency interpretation as non-diagnostic. The 0.60, 0.90 and +0.05 thresholds are production-package design defaults, not literature-derived constants or a claim of separate author approval. No effect size or power is inferred from the four-step smoke runs. Before costly execution, use independent pilot seeds outside 101-108 to estimate variance and decide whether eight pairs are adequate; any change to n or thresholds must create a new plan hash before sealed results are available. Do not tune the minimum effect to the pilot estimate itself.

A null/negative result is substantive. If both arms fail basic competence, repair the developmental environment and treat SYS as non-diagnostic for representation efficiency. If the baseline is competent and B does not improve under the declared envelope, record that operationalization as unsupported; do not automatically move to an easier task until it wins. A confidence interval spanning both meaningful benefit and harm is inconclusive, not proof of equivalence.

## Secondary analysis and cost

Secondary outcomes: counterfactual-pair consistency; per-family/per-stage accuracy; contradiction/unknown discrimination; retention after a matched 256-step interference branch; exposure-to-mastery censored at the cap; parameter/exposure scaling; ordinary and reversed input traversal; cross-codec transfer. Report estimates and uncertainty without converting a favorable secondary result into the primary success criterion. A later confirmatory secondary family uses multiplicity control, such as Holm over its explicitly fixed tests, in a new locked plan.

Cost advantage is a separate claim. Require repeatable total measured-cost reduction of at least 20% at quality noninferiority margin -0.02, with amortization and hardware denominators explicit. These thresholds are design choices. Include compiler/ontology engineering, teacher generation, rejected proposals, learner, evaluation, recovery and human operation. Unknown energy remains null. The reference's token-count difference is not a measurement of GPU-hour or energy savings.

## Launch acceptance and deviations

The current reference runner intentionally rejects `CONFIRMATORY`. Acceptance requires independent custody, clean-room operator regeneration, actual local-model identity and metrology, stronger leakage audit, exact plan/ABI/source/config hashes, and a controlled evaluator wrapper. Changing the guard without those receipts is prohibited by this plan. Main training is not authorized on newly paid resources by this package.

A transient interrupted run resumes only from a complete checkpoint with the same source/config identity. A changed source, dependency, intervention privilege or family implementation creates a new lineage and invalidates direct pooling unless the amendment explicitly models it. All attempted seeds remain in the run inventory. Material post-unblinding changes are exploratory. The plan does not grant deployment, publication, external compute spend or release of private data.
