# Reproducibility acceptance matrix

| Surface | Delivered state | Exact remaining acceptance |
|---|---|---|
| Finite worlds and oracle pair | Executable, property-tested | Independent specification/oracle review |
| Bilqis/CNL/mixed/isomorphic codecs | Executable, reversible on tested domains | Full donor morphology is a different extension |
| Scratch student and two precisions | Executable, four tiny runs | Reference-scale competence and matched resource frontier |
| Teacher and promotion policy | Executable deterministic policy | Adaptive local-model interaction under locked identity |
| Proposal replay and local event adapter | Executable, append-only events and replay/loopback boundary tests | Actual identified Qwen service integration, hardware and token-usage receipts |
| Checkpoint resume and condition fork | Ordinary/pre-probe tensor-identical recovery; explicit fork tested | Cross-hardware equivalence and causal attribution data |
| Seal generation/opening | Executable local commitment checks | Separate custodian, unexamined families, restricted scoring access |
| Primary world sensitivity | Witness construction and paired scoring implemented and tested | Confirmatory-scale evaluation with independent custody |
| Exact-hash collision exclusion | Implemented | Isomorphic/template duplicate audit |
| Statistics | Seed-level exact sign-flip and t interval | Main-trial input data, which do not yet exist |
| Environment | Observed versions and direct pins | Hash-locked transitive wheelhouse on receiving platform |
| Human reproducibility | Agent-local smoke only | Independent operator regeneration without tacit help |
| Native ternary efficiency | Not measured | Packed-kernel port and actual hardware energy/memory measurement |
| Later natural-language transfer | Design specified | Full codec/LM training and held-out transfer study |

These gaps are bounded implementation or empirical acceptance tasks. They do not erase the delivered reference. They prevent it from being misrepresented as a completed scientific experiment.
